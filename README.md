# 庙算本地兵棋辅助工具

基于 `data/可视化.html` 的六角格地形可视化与战场分析工具，用于兵棋推演复盘：查看高程、地物、道路、河流，并做通视与视野分析。

## 目录结构

```
兵棋复盘系统/
├─ 启动可视化.bat              本地启动脚本
├─ README.md
└─ data/                       网站根目录（服务器必须指向这里）
   ├─ 可视化.html              主页面（单文件，CSS/JS 全部内联）
   ├─ maps/
   │  └─ map_<id>/basic.json   地图数据，一个文件夹一张图
   └─ scenarios/               想定数据
```

## 快速开始

1. 双击 `启动可视化.bat`。
2. 脚本会自动：切换到 `data` 目录 → 找到 Python → 启动本地静态服务 → 打开浏览器。

默认地址：

```
http://127.0.0.1:8000/可视化.html
```

关闭控制台窗口或按 `Ctrl+C` 即停止服务。

### 换端口

在命令行里给脚本传一个参数即可：

```
启动可视化.bat 8001
```

对应地址变为 `http://127.0.0.1:8001/可视化.html`。

### 手动启动

不想用脚本时，在 `data` 目录下执行任意静态服务器：

```
python -m http.server 8000 --bind 127.0.0.1
```

## 页面操作

| 操作 | 说明 |
| --- | --- |
| 滚轮 | 缩放地图 |
| 拖拽 | 平移地图 |
| 双击 | 复位视图 |
| 地图下拉框 | 切换 `maps/` 下的地图，自动扫描目录 |

左侧信息面板：

- **高程**：当前地图的相对高差区间（最低点记为 0，单位米）。
- **格子**：当前地图的格子总数。
- **数字**：勾选后显示每格的高程与坐标，取消则只显示地形色块。
- **工具 / 测通视**：依次点击两个格子，绘制连线并给出距离（格）与通视判定；不通视时标出阻隔的格子。
- **工具 / 周边视野**：点击一个格子，绿色高亮其可见范围内的所有格子。
- **范围**：周边视野的半径，默认 20 格，可改为 1–60。
- **工具 / 清除**：清除所有绘制结果。

## 地图数据格式

`data/maps/map_<id>/basic.json`：

```json
{
  "map_id": 29,
  "ele_grade": 20,
  "map_data": [
    [
      {
        "pos": 2339,
        "elev": 4600,
        "cond": 0,
        "roads": [0, 0, 0, 0, 0, 0],
        "rivers": [0, 0, 0, 0, 0, 0],
        "neighbors": [2340, 2240, 2239, 2338, 2439, 2440]
      }
    ]
  ]
}
```

`map_data` 是二维数组（行 × 列）。顶层字段：

| 字段 | 含义 |
| --- | --- |
| `map_id` | 地图编号，与文件夹名 `map_<id>` 一致 |
| `ele_grade` | 高程等级间隔（米），`elev` = 等级 × 该值 |

每格字段：

| 字段 | 含义 |
| --- | --- |
| `pos` | 格坐标，`行号 × 100 + 列号`，如 `2339` = 第 23 行第 39 列 |
| `elev` | 海拔（米） |
| `cond` | 地物：`0` 平地、`1` 丛林、`2` 居民地 |
| `roads` | 长度 6 的数组，按方向给出该方向的道路等级：`0` 无路、`1/2/3` 为道路等级 |
| `rivers` | 长度 6 的数组，非 `0` 表示该方向有河流 |
| `neighbors` | 长度 6 的邻格 `pos`，按下面方向序号排列；越界为 `-1` |

方向序号（尖顶六角格，奇数行偏移）：

```
0=E  1=NE  2=NW  3=W  4=SW  5=SE
```

## 常见问题

**页面打不开 / 一片空白**

不要直接双击 `可视化.html` 用 `file://` 打开，浏览器会拦截 `fetch` 读取 JSON。必须通过上面的本地服务访问。

**下拉框里的地图不全**

页面通过读取 `maps/` 目录列表自动发现地图。若服务器不支持目录浏览，会退回内置列表；此时把新地图加入内置列表或换用支持目录列表的服务器（本脚本的 `python -m http.server` 支持）。

**提示找不到 Python**

脚本先用 PATH 里的 `python`，失败后再探测常见的 Anaconda / Miniconda / 官方安装目录。都没有时请安装 Python，或把 Python 加入 PATH。

**端口被占用**

换一个端口重开，例如 `启动可视化.bat 8001`。

**局域网其他设备访问**

把脚本里的 `--bind 127.0.0.1` 改成 `--bind 0.0.0.0`，再用 `http://<本机IP>:8000/可视化.html` 访问。
